Privacy Policy

Last updated: 8 November 2026

LiveApp is a private tool used only by its developer to manage the developer's own YouTube channels.

Data accessed

With the channel owner's permission (Google OAuth, YouTube Data API), LiveApp reads the owner's live broadcasts, live chat messages and public statistics (viewers, likes, views), and updates the title, description and tags of the owner's own live broadcasts.

Use and storage

Chat messages and statistics are only displayed on the owner's own stream overlay and are not stored, sold or shared. The OAuth token is kept on the owner's own computer and is never shared with anyone.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

LiveApp's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. LiveApp uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Contact

Use the developer support email shown on the Google consent screen.
